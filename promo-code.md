## Promo Code क्या है?

Promo code एक promotional code हो सकता है जिसका उपयोग किसी eligible promotion, offer या campaign के अंतर्गत किया जाता है।

किसी भी promo code की validity, eligibility और benefits संबंधित platform या promotion की terms पर निर्भर करते हैं।

हर code सभी users या सभी समय पर उपलब्ध हो, यह आवश्यक नहीं है।

## Spin Crush Promo Code का उपयोग

यदि किसी promotion के लिए promo code उपलब्ध है, तो सामान्य प्रक्रिया इस प्रकार हो सकती है:

1. संबंधित platform की current promotion information देखें।
2. Promo code की validity और expiry date जांचें।
3. Code के लिए eligibility requirements पढ़ें।
4. Code को सही field में enter करें।
5. Submit करने से पहले code को दोबारा check करें।
6. Promotion apply होने के बाद उसकी conditions समझें।

Actual redemption process platform के अनुसार अलग हो सकता है।

## Promo Code की Validity

किसी promo code का उपयोग करने से पहले इन बातों की जांच करें:

* Code अभी active है या नहीं
* Expiry date क्या है
* कौन से users eligible हैं
* Minimum requirements क्या हैं
* कौन से games या services पर लागू होता है
* किसी wagering या अन्य condition की आवश्यकता है या नहीं
* Promotion कितने समय तक उपलब्ध है

Expired या invalid code को redeem नहीं किया जा सकता।
